# 2024 clearance inventory return rule (v1, EXPIRED)

2024 clearance inventory could be returned within **7 days of delivery**.

**This policy expired 2024-12-31 and has not been renewed for subsequent
clearance cycles.** Because a SKU-specific document exists for
`CLEARANCE-ITEM` in `US` (this one), `evaluate_policy` does NOT fall back to
the global 30-day policy once this expires — a lapsed category-specific rule
is a genuine coverage gap, not something the generic default should paper
over. Requests for `CLEARANCE-ITEM` returns after 2024-12-31 must be
escalated until Merchandising publishes a renewal.

## Change history

- v1 (2024-01-01 – 2024-12-31): Initial and, to date, only clearance return
  rule. No successor has been published.
