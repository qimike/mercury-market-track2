# /review-answers

Review one or more input artifacts such as prompts, suggestion packets, support drafts, or changed files.

Evaluate:

- factual grounding
- policy support
- effective dates
- provenance
- unsupported certainty
- missing information
- proposed-action safety
- customer-facing clarity
- internal rationale separation
- human approval requirement
- cross-issue consistency
- duplicate remedies
- schema compatibility

Return:

- overall status
- blocking findings
- non-blocking findings
- exact evidence
- affected file or object
- rule reference
- finding ID
- fingerprint
- suggested correction
- confidence

This command never executes a proposed action.
